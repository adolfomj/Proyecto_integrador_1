# Sistema de Gestión y Análisis de Multiimplantaciones

Sistema web desarrollado para gestionar y analizar las multiimplantaciones de productos y su comportamiento en las ventas semanales.

## Descripción

El proyecto busca facilitar el registro y seguimiento de las multiimplantaciones realizadas sobre los productos, permitiendo almacenar información sobre los productos, las ubicaciones y las ventas semanales.

A partir de la información registrada, el sistema permite consultar el historial de las multiimplantaciones y comparar el comportamiento de las ventas antes y después de una intervención.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Supabase
- Base de datos PostgreSQL

## Objetivo

El objetivo del proyecto es desarrollar una herramienta que permita organizar la información de las multiimplantaciones y analizar su relación con el comportamiento de las ventas, facilitando el seguimiento de estas acciones comerciales mediante datos históricos.

## Alcance

La aplicación está enfocada en la gestión de productos, multiimplantaciones y ventas semanales. La primera versión no contempla la gestión de inventarios, compras, proveedores ni el cálculo de rentabilidad o margen.
